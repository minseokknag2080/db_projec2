# db_projec2# 🔥 산불 실시간 시뮬레이터 & MP4 다운로더 (v5.2)

> **실제 지형 데이터와 기상 환경 변수를 연동하여 산불 확산을 실시간 모의하고, 임도(Forest Road)의 방재 성능을 정량적으로 검증하는 웹 기반 수치 해석 시뮬레이션 플랫폼입니다.**

배포 링크를 통해 언제 어디서나 브라우저에서 직접 산불 시뮬레이션을 가동하고 모의 영상을 다운로드할 수 있습니다.

## 📌 주요 핵심 기능 (Key Features)

본 플랫폼은 복잡한 백엔드 구조 없이 사용자가 브라우저에서 직접 직관적으로 제어하고 결과를 시각적으로 획득할 수 있도록 UI/UX 중심으로 설계되었습니다.

### 1. ⚙️ 사용자 맞춤형 3대 환경 제어 (Interactive Controls)
왼쪽 사이드바 메뉴를 통해 대한민국 사계절 기후 특성 및 산림 환경 변수를 자유자재로 튜닝할 수 있습니다.
* **계절별 확산 확률 설정:** 연간 평균 범용 기준값부터 봄철 대형산불 조심기간(극도 건조기 위험 상황), 여름·가을철(습한 환경)까지 사계절 산림 상태를 마우스 드래그로 손쉽게 세팅합니다.
* **실시간 기상(풍향·풍속) 매칭:** 바람의 세기(m/s)와 8방향 풍향 벡터를 조합하여 기상 악화 시나리오를 완벽하게 모의합니다.
* **원하는 만큼 시간(타임스텝) 조절:** 초기 국소 확산 단계부터 최대 200단계에 이르는 대형 산불 확산까지 시뮬레이션 지속 시간을 자유롭게 지정할 수 있습니다.

### 2. 🖼️ 화면에 펼쳐지는 3대 실시간 시각 연출 (Visual Interaction)
"산불 실시간 시뮬레이션 가동" 버튼을 누르는 즉시, 중앙 대시보드 도화지 위에 지형과 바람이 융합된 물리 현상이 렉(Lag) 없이 실시간 라이브로 렌더링됩니다.
* **⛰️ 오르막길 폭발적 확산 (지형 효과):** 불길이 평지보다 경사가 가파른 산악 오르막길을 만났을 때, 화면 위에서 붉은색(`Reds`) 화선이 순식간에 치고 올라가는 다이내믹한 확산 속도 차이를 구현했습니다.
* **🌪️ 바람을 타고 쏠리는 타원형 화선 (기상 효과):** 강풍 환경 구동 시 불길이 사방으로 둥글게 번지는 현상을 넘어, 순풍 방향으로 길쭉하게 밀려 나가고 역풍 방향은 억제되는 실제 **타원형(Ellipse) 불길**을 생생하게 연출합니다.
* **🚧 임도(산길)의 철벽 방어선 (방재 효과):** 화면 속 파란색 임도 실선 네트워크를 만나는 순간, 불길의 전진이 턱턱 걸리며 정체되거나 저지되는 진짜 방화선(Firebreak) 효과를 시각적으로 직접 확인하고 검증할 수 있습니다.

### 3. 📥 최종 결과물 및 파일 내보내기 (Outputs)
시뮬레이션 모의가 최종 완료되면 사용자는 분석 데이터 및 소장용 미디어 파일을 즉시 획득합니다.
* **소장용 고화질 MP4 영상 다운로드:** 화면에서 실시간으로 번지던 산불 애니메이션 과정 그대로를 담은 고화질 `.mp4` 동영상 파일(12 FPS)을 클릭 한 번으로 내 컴퓨터 다운로드 폴더에 즉시 저장합니다. (학술 발표 및 PPT 삽입용으로 최적화)
* **피해 규모 정량 요약 리포트:** 최종 턴 종료 후 소실된 총 격자 조각 개수와 정밀하게 계산된 최종 피해 면적($m^2$)을 대시보드 하단에 큼직한 메트릭 카드로 표출하여 직관적인 통계를 제공합니다.
